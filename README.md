# ⚾ 野球人生（仮題）

1 人の野球人の人生を遊ぶブラウザゲームです。選手として入団し、引退したあとは、届いた話から監督・コーチ・GM の仕事を選びます。
役職は固定されません。成績とオーナーの評価で、続投・解任・引き抜きが起き、球団を渡り歩きます。

土台は `baseball` フォルダの「ペナント監督」の試合とリーグの計算です。HTML / CSS / JavaScript だけで動き、ビルドは要りません。

## 動かし方

**`スマホで遊ぶ.bat`** をダブルクリックして、パソコンなら `http://localhost:8010` を開きます（スマホは同じ Wi-Fi で、画面に出るアドレス）。
`index.html` を直接開いても動きます。

元のゲームのポート（8000）と分けてあります。セーブの名前も別なので、元のゲームのセーブには触りません。

## 遊びの流れ

1. **現役時代**：名前・投手か野手か・入団までの道だけ選ぶ。球団と才能は運。1 年ずつ追うか、引退まで飛ばす
2. **引退**：現役の成績と評判で話が来る。スターには古巣から監督の打診。無名でも、縁のある球団がコーチの席を用意する
3. **仕事**：条件を「安定・標準・勝負」から選ぶ。オーナーのノルマを追う
4. **査定**：信頼度が解任の目安を切ると解任。契約が切れれば更新か退任。ほかの球団から引き抜きの話も来る
5. **無職**：3 年話がないと引退。最後に人生の経歴書が出る

「じぶん」の画面の**じぶん年表**に、毎年の成績と、入団・トレード・タイトル・引退・就任・解任などが残ります。

**スコアは生涯収入**です（現役の年俸 ＋ 仕事の年俸 ＋ ボーナス）。ノルマ達成と日本一でボーナスが出ます。解任されたときに受け取れる残り年俸は半分です。上位 10 件はこのブラウザのタイトル画面に残ります。

## 役職でできること

| 役職 | 自分で動かす画面 | 主に評価されること |
|---|---|---|
| 監督 | 一軍・二軍、オーダー、采配方針 | 順位（オーナーによって若手の起用や人気） |
| 投手コーチ | 投手の練習方針、投手ごとの重点 | 若手投手の伸び（12 球団の中の順位） |
| 野手コーチ | 野手の練習方針、野手ごとの重点 | 若手野手の伸び（12 球団の中の順位） |
| GM | トレード、FA、ドラフト、経営、施設、自由契約 | 順位、収支（12 球団の中の順位）など |

引退した人の中から、現役の功績と評判と日本一の数で侍ジャパンの監督・コーチが選ばれます。大会の結果で評判と報酬が変わります。

- **代表の監督**：専任です。大会の前の年のオフに打診が来て、受けると球団の仕事を辞めて大会まで専念します。断ることもできます
- **代表のコーチ**：大会の年に選ばれます。球団の仕事（監督・コーチ・GM）と兼ねられます

コーチの話は、現役のときの専門（投手か野手）の席だけ来ます。自分の担当でない部分は AI が動かします。監督・コーチのときは、フロントに要望を出せます（発言力と信頼度が高いほど通ります）。

## ファイル

| ファイル | 中身 |
|---|---|
| `js/career.js` | 人生の計算：現役の記録、オーナー、契約、信頼度、評判、解任、オファー、フロント AI。**数値はすべてここの上のほうにあり、仮（AI）** |
| `js/ui_career.js` | 人生の画面と、役職ごとに開く画面・操作の決まり |
| `js/data.js` `player.js` `sim.js` `league.js` `ui.js` `main.js` | 元のゲームからのコピーに手を入れたもの |
| `tools/測定.html` | AI まかせで人生を何本も回し、解任率や在任年数を数える。`http://localhost:8010/tools/測定.html` で開く |

## 元のゲームとの関係

試合とリーグの計算だけを土台にしています。元のゲームのセーブファイルは読み込めません。

## 作りのメモ

- `S.myTeamId` は「いま追っている球団」です。現役や無職のときも入っています。操作できるかどうかは `hasControl('roster' | 'train' | 'front')` で決まります
- ゲームの数値を決めるのは人です。今の値は AI が置いた仮のもので、`tools/測定.html` で測った結果を見て決めます
